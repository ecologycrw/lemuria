# Lemuria

> Nome provisório. *Lemuria is an open source C++ client engine for building classic-style MMORPGs. Documentation is currently in Portuguese.*

O Lemuria é uma engine open source, escrita em C++, para desenvolvedores criarem o cliente de MMORPGs no estilo clássico: mapas em grade, câmera em 3/4, clicar para andar, combate por alvo e itens com nível e opções.

O Lemuria é **só o cliente**. Cada desenvolvedor liga a engine ao servidor do jogo dele, por meio de um adaptador de protocolo.
